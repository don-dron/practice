Набор команд для практики practice-htr на Windows 11 с GPU NVIDIA (CUDA)
================================================================================

0) Установите заранее
---------------------
- NVIDIA Driver (актуальный с сайта NVIDIA).
- Python 3.9–3.12 с python.org («Add Python to PATH» при установке) или установка только для пользователя и явный PATH.
- Git (опционально, для clone). Данные: из корня репозитория `scripts\archive_data_datasets.cmd fetch`, затем `scripts\unzip_datasets.cmd` (см. README); при желании можно те же действия выполнить через Git Bash или WSL и `./scripts/*.sh`.


1) Каталог проекта и виртуальное окружение (cmd.exe)
----------------------------------------------------
cd путь\к\practice

py -3.11 -m venv .venv
.\.venv\Scripts\activate.bat

python -m pip install -U pip wheel


2) PyTorch сборка с поддержкой CUDA (под вашу версию CUDA)
------------------------------------------------------------
Подберите строку установки здесь и скопируйте одну команду как на сайте:
https://pytorch.org/get-started/locally/

Пример для CUDA 12.1 через официальный индекс сборок (замените при необходимости):

pip install torch torchvision torchaudio --index-url https://download.pytorch.org/whl/cu121

Проверка:

python -c "import torch; print('CUDA:', torch.cuda.is_available()); print(torch.cuda.get_device_name(0) if torch.cuda.is_available() else 'CPU only')"


3) Установка пакета practice-htr в editable-режиме
----------------------------------------------------
Всё ещё в активированном .venv и в корне репозитория:

pip install -e .


Данные Digital Peter должны быть на месте: data\digital_peter\annotations_train.json и папка data\digital_peter\images\ (разархивация через README / скрипты).


4) Обучение E1 Digital Peter на CUDA
-------------------------------------

Вариант A — если команда htr-train появилась после pip install (предпочтительно):

htr-train --config configs\default.yaml --config configs\baselines\4_01_line_crnn_ctc_digital_peter.yaml --device cuda --epochs 20

Вариант B — без установки editable, из корня репозитория (cmd), с PYTHONPATH:

set PYTHONPATH=%CD%\src
python -c "import sys; from htr.cli import train_main; sys.argv=['htr-train']+sys.argv[1:]; train_main()" --config configs\default.yaml --config configs\baselines\4_01_line_crnn_ctc_digital_peter.yaml --device cuda --epochs 20

Вариант C — полный путь к Launcher в venv (если activate не добавил Scripts в PATH):

.\.venv\Scripts\htr-train.exe --config configs\default.yaml --config configs\baselines\4_01_line_crnn_ctc_digital_peter.yaml --device cuda --epochs 20

Чекпоинты по умолчанию: training\checkpoints\latest.pt


5) Сравнение с базой T0 (§5.1.2 — один default: без второго профиля)
---------------------------------------------------------------------
htr-train --config configs\default.yaml --device cuda


6) Полный регистр §5.1 + CUDA — все указанные в отчёте цепочки YAML
==================================================================
Ниже — те же связки, что в п. 5.1.2 и блоке команд там; при желании добавьте
единые параметры в конец каждой строки при необходимости:  --epochs 20 --device cuda  (пропускная способность: цель быстрее кормить GPU — в ``default.yaml`` больше ``num_workers``/``batch``, DataLoader с ``persistent_workers`` и ``prefetch_factor``, AMP и TF32; при полной занятости GPU низкая средняя загрузка CPU нормальна; без потолка воркеров на Win: ``set HTR_WIN_MAX_NUM_WORKERS=0``; при OOM уменьшить ``batch_size``).
Обучаемые связки T0–E2 и профили регистра S2–S5 (добавьте префиксы `--device cuda` и нужные `--epochs`, `--batch-size`):

htr-train --config configs\default.yaml

htr-train --config configs\default.yaml --config configs\baselines\4_01_line_crnn_ctc_digital_peter.yaml

htr-train --config configs\default.yaml --config configs\digital_peter_line_ctc.yaml

htr-train --config configs\default.yaml --config configs\baselines\overlay_comparable_line_budget.yaml --config configs\baselines\4_01_line_crnn_ctc_digital_peter.yaml
Связки S2–S5 активируют реализованные в коде топологии (§4.2 CE, §4.3–4.5 CTC; для §4.4 строковый этап без детектора страницы). При `pretrained_resnet_line_ctc` первый импорт может скачать веса ResNet через torchvision.

htr-train --config configs\default.yaml --config configs\baselines\4_02_line_stub_encoder_decoder_attention.yaml

htr-train --config configs\default.yaml --config configs\baselines\4_03_line_stub_transformer_encoder_attention.yaml

htr-train --config configs\default.yaml --config configs\baselines\4_04_page_stub_detector_then_line.yaml

htr-train --config configs\default.yaml --config configs\baselines\4_05_line_stub_transfer_pretrained_encoder.yaml


7) Инференс по сохранённой модели (пример)
--------------------------------------------
Подставьте путь к кропу строки:

htr-infer --checkpoint training\checkpoints\latest.pt --device cuda путь\к\строке.png

Или без editable (рядом с вариантом B для обучения):

set PYTHONPATH=%CD%\src
python -c "import sys; from htr.cli import infer_main; sys.argv=['htr-infer']+sys.argv[1:]; infer_main()" --checkpoint training\checkpoints\latest.pt --device cuda путь\к\строке.png


8) PowerShell (альтернатива активации venv)
-------------------------------------------
cd путь\к\practice
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1

Если «execution policy» запрещает скрипты, один раз для текущего пользователя:
Set-ExecutionPolicy -ExecutionPolicy RemoteSigned -Scope CurrentUser


9) Все связки регистра §5.1 подряд (T0, E1, E1*, E2, S2–S5) на CUDA
---------------------------------------------------------------------
Из корня репозитория в cmd.exe (venv можно не активировать — скрипт возьмёт `.venv\Scripts\python.exe`, при отсутствии попытается создать `.venv`):

scripts\train_registry_all.cmd --device cuda

По умолчанию при пустых аргументах подставляется `--device cuda`.

Перед первым запуском на GPU скрипт сам выполняет: `pip install -U pip`, `pip install -e .` в выбранный интерпретатор; если `torch.cuda.is_available` всё равно ложь — переустанавливает PyTorch из колёс **cu124**, затем **cu121** (нужен интернет).

Отключить автоматический pip/cu-колёса: `set TRAIN_REGISTRY_SKIP_CUDA_PIP=1`. Свой интерпретатор Python: `set TRAIN_REGISTRY_PYTHON=C:\полный\путь\python.exe`. Тихий режим pip (`-q`): `set TRAIN_REGISTRY_PIP_QUIET=1`.

Перед pip скрипт проверяет наличие `pip` и при необходимости выполняет `python -m ensurepip`; шаги подписаны `Step:` в консоли, чтобы было видно, на чём упало.

После попытки bootstrap, если CUDA по-прежнему недоступна: код выхода **3**. Сбой pip / venv внутри bootstrap: **4**. PyTorch ставится с колёс cu124 и cu121, но `cuda.is_available` остаётся ложью: **5** — чаще нет NVIDIA в этой учётке, драйвер, VM, или смотрите вывод `nvidia-smi` в конце скрипта. Намеренно только CPU: `set TRAIN_REGISTRY_ALLOW_CPU=1` или `--device cpu`.

Снимки каждой модели сохраняются в папку `training\registry_snapshots\` (файлы вида `T0_latest.pt`, `E1_latest.pt`, …), чтобы поток прогонов не затирал последний чекпоинт.

Опционально из cmd до вызова задать переменные окружения:

set TRAIN_REGISTRY_EPOCHS=1

set TRAIN_REGISTRY_BATCH=8

scripts\train_registry_all.cmd --device cuda

Полный бюджет эпох берётся из YAML, если не задано `TRAIN_REGISTRY_EPOCHS`. Для связки S5 при первом запуске может потребоваться загрузка весов ResNet (нужен интернет, пока кэш torchvision пуст).


11) Скачивание данных на Windows (без Git Bash)
-----------------------------------------------
Из корня репозитория в cmd:

scripts\archive_data_datasets.cmd fetch
scripts\unzip_datasets.cmd

Альтернатива: archive_data_datasets.sh и unzip_datasets.sh из Git Bash или WSL.


Примечания
----------
- Если не хватает VRAM, уменьшите --batch-size (например 4).
- Если torch видит только CPU — переустановите torch с нужным индексом (--index-url) под ваш драйвер и версию CUDA.
- Пути в --config можно писать и через слэш configs/default.yaml — Python их обычно принимает.
